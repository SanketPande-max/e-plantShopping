# e-plantShopping

## Paradise Nursery Shopping Application

**Paradise Nursery** is an online plant shopping application developed using React.js, Redux Toolkit, JavaScript, HTML, and CSS as part of the IBM Full Stack Software Developer course final project.

### Project Overview

The application allows users to browse different categories of houseplants, add plants to their shopping cart, manage quantities, and view the total purchase amount.

### Features

- Attractive landing page with a background image and Get Started button.
- Product listing page with different categories of houseplants.
- Plant cards displaying images, names, descriptions, and prices.
- Add to Cart functionality using Redux Toolkit.
- Dynamic shopping cart icon displaying the total quantity.
- Increase and decrease product quantities.
- Remove products from the shopping cart.
- Automatic calculation of item subtotals and cart total.
- Continue Shopping and Checkout buttons.
- Responsive user interface.

### Technologies Used

- React.js
- Redux Toolkit
- React Redux
- JavaScript
- HTML5
- CSS3
- Vite

### Installation and Setup

Clone the repository:

```bash
git clone https://github.com/SanketPande-max/e-plantShopping.git
```

Navigate into the project folder:

```bash
cd e-plantShopping
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
